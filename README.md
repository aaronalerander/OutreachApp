# Outreach

A Chrome extension (Manifest V3) for saving the LinkedIn profile you're viewing.
Click the toolbar icon, then **Capture profile** to get the person's name and
LinkedIn URL as JSON. Nothing runs until you click the button.

## Run locally

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select the `chromeExtension/` folder.
4. Pin the extension from the puzzle-piece menu, then click its icon to open the popup.

After editing files, click the reload icon on the extension's card in `chrome://extensions`.
